# Windows runtime for this installation

Use the Python interpreter at D:/ChatGPT_Data/.codex/runtimes/nature-skills/python/Scripts/python.exe for bundled helpers. Word export commands are in the adjacent Scripts directory.

For R figures, set R_LIBS_USER to D:/ChatGPT_Data/.codex/runtimes/nature-skills/r-library in the shell that invokes Rscript.

For Node.js scripts, the installed Node 24 runtime at D:/ChatGPT_Data/.codex/runtimes/playwright/node/node.exe is also available if the current PATH lacks Node.
For the optional Python Playwright route used by the published-patent search, set PLAYWRIGHT_BROWSERS_PATH to D:/ChatGPT_Data/.codex/runtimes/nature-skills/browser-cache in that task's shell.

The user-level Codex MCP server nature-academic-search runs the bundled academic search server. Individual providers use credentials or contact information according to their own requirements.
